# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, please report it responsibly:

- **Email:** omarmohamed909@svnu.edu *(replace with your actual email)*
- **Response Time:** We aim to respond within 48 hours and will work with you to release a fix as quickly as possible.

### What to Include in Your Report

1. A description of the vulnerability and its potential impact.
2. Steps to reproduce the issue.
3. Any proof-of-concept code, if applicable.
4. Your recommended fix (optional but appreciated).

We appreciate your help in keeping QNU secure for all users.
